# Netflix Data Analytics Dashboard

## Project Overview
This project analyzes Netflix customer data using SQL, Microsoft Excel, and Power BI. It focuses on customer demographics, subscription plans, account status, revenue, viewing hours, ratings, content preferences, and device usage.

## Tools & Technologies
- **SQL:** Data querying, filtering, aggregation, and analysis
- **Microsoft Excel:** Data cleaning and preliminary analysis
- **Power BI:** Interactive dashboard, data visualization, and KPI reporting
- **DAX:** Measures and calculated metrics

## Dashboard Highlights
The Power BI dashboard presents the following KPIs:

- Total Customers: 995
- Active Customers: 705
- Total Revenue: 7M
- Average Watch Hours: 42.61
- Average Rating: 3.75

## Key Analysis
- Customer distribution by subscription plan
- Customer distribution by country
- Account status analysis: Active, Cancelled, and Paused
- Genre preferences and content type distribution
- Device usage across different platforms
- Customer engagement and revenue metrics

## Project Files
- `SQL/` — SQL queries used for data analysis
- `Excel/` — Excel workbook and analysis
- `PowerBI/` — Power BI dashboard file
- `Screenshots/` — Dashboard preview

## Objective
To transform customer data into meaningful business insights that help understand subscription trends, customer engagement, content preferences, and account retention.
